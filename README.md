# 📅 Minha Agenda

Uma aplicação simples de agenda de compromissos construída com **HTML, CSS, JavaScript** e integrada ao **Supabase** para persistência de dados.

---

## ✨ Funcionalidades
- [Adicionar tarefas](ca://s?q=Como_adicionar_tarefas_no_Supabase) com título, data, hora e local.
- [Listar compromissos](ca://s?q=Como_listar_compromissos_no_Supabase) em tempo real.
- [Marcar como concluído](ca://s?q=Como_marcar_tarefa_como_concluida_no_Supabase) ou desmarcar.
- [Excluir compromissos](ca://s?q=Como_excluir_tarefas_no_Supabase).
- Persistência de dados no Supabase (CRUD completo).

---

## 🛠️ Tecnologias utilizadas
- **HTML5** para estrutura.
- **CSS3** para estilização.
- **JavaScript (ES6+)** para lógica.
- **Supabase** como banco de dados e autenticação.
